Assess a project

GitHub repository or a local folder that is a git repository.
What happens when you press Assess
  1. GitHub repos are cloned into a local cache; local folders are read in place and never modified.
  2. About 70 automated checks run on the latest commit and are judged against the chosen profile of capabilities.
  3. The same checks re-run on 8 past commits, and git history is measured, for the Dynamics view.
Runs locally, takes 1–2 minutes, no AI involved. The result is saved as a new run in runs/.
